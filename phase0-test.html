Multi-Game Watcher — Phase 0 test

This page loads four streams in a 2×2 grid to check which broadcasters allow third-party iframe embedding on iPad.

Before you start

  1. In a separate Safari tab, open each of watch.sportsnet.ca, tv.bell.ca, and tsn.ca and sign in with your TV provider. This drops session cookies that the iframes on this page will reuse.
  2. Come back to this tab, rotate your iPad to landscape, and tap Start test below.

What to look for

  1. YouTube pane should load and play muted on its own (the reference case).
  2. Sportsnet / Bell / TSN: each iframe may (a) load the normal site → good, (b) show an error / refuse to display → iframe blocked, (c) load but refuse to play video → DRM or player-restriction issue. Note which per pane.
  3. Tap the YouTube pane to switch audio — if the badge flips to green and you hear sound, the core interaction is proven.
  4. Sports panes can't be mute-controlled from outside in a web page — so tap them just to see the focus change; use each site's own mute button for audio.
